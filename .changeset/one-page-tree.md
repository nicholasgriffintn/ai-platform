Teammates, routines, plugins, files, canvas, apps, tools and skills are one page each, whether you open them from Chat or from inside a project.

- The same page now serves both places and reads which one you are in from the address, so a project's teammates, files and plugins behave exactly like your personal ones with the project header and tabs added.
- The desktop app lists both addresses for each of these pages instead of carrying a second copy, and its window title still says "Project files" or "Project teammates" when you are inside a project.
