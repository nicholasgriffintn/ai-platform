Claude Code now runs as a proper session in the desktop app, like Codex: replies and steps stream in, tool use asks for your approval, and the conversation keeps its folder and session between messages. Both agents run with your own subscription login, and Polychat warns you when one is signed in with an API key that bills per token. Chats in Polychat on the web can now use the agents on your desktop with the same streaming and approvals. In Settings you can let your workspaces use your desktops, so Work tasks run with Claude Code or Codex on members' machines instead of spending Polychat credits. Teammates working on someone's desktop can read and update tasks through Polychat, leave that person's own agent instructions out, and a desktop can work on up to three jobs at once. When a task is waiting for your approval, its page now offers Review request, and approving picks the agent up exactly where it paused.
