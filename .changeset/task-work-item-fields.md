Give a project task the fields a work item needs: acceptance criteria as separate checkable items, an expected deliverable, context, constraints including tools withheld from the run, dependencies that gate a start, a per-task approval policy, priority and a due date. Enforced fields and descriptive ones are stated separately so neither is mistaken for the other.
