Workspaces can now hold seats and share one pool of credits. Each member and pending invitation takes a seat, and everyone in the workspace can see seats and pool use on the new team plan view. Work inside the workspace draws on the shared pool instead of each person's own account, and it stops when the pool is spent. Personal API keys stay personal: they are never used for pooled work, and keep working in your own conversations.
