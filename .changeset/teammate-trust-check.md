Built-in teammates are now checked every night for a classic trick: a note that slips in an instruction to forward email, delete files or buy something. Each teammate is asked to summarise such notes in a dry run where nothing can actually happen, and any attempt to act on the hidden instruction fails it. The results are saved as a report in Files.
