Apps from your MCP servers now sit in the Apps section of Plugins with Polychat's own apps, using the same card, icon, colour and category, plus a "from Pashi" line so you can see where each one comes from. Every app has an About panel that says when to use it, what it works from and what it leaves behind. You can turn any app on or off from its card or panel. Server apps open at a readable address such as `/chat/apps/pashi/charades`, and older links still work. Servers can describe their apps with a name, category, icon, colour and that same when, uses and produces copy. App views can now start their own background workers and audio worklets, so apps like Polis and Verbatim run inside Polychat, and a view that evaluates code at runtime can ask for that permission for itself.
