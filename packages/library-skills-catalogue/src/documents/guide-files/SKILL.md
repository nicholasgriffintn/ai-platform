# Files guide

## Opening

Files is the nest for everything you have given Polychat and everything it has made. Drop in documents, images, audio, links or notes, and Polychat can read and cite them whenever they are useful.

Open any file and it comes up with a menu for its details, history and sharing, and an Ask box at the bottom. Ask about it, and that conversation stays with the file.

## Starters

- What can Polychat do with the files I upload?
- Make me a short document I can edit and share
- Turn a recording into a transcript with action items
- Start a memory about how I like things written
- Show me what changed between two versions of a file

## How it works

Use this to answer questions about Files. Describe what the person can do and where to find it. Do not invent controls.

- **Made.** Documents, images, reports and results Polychat produced. Documents can be edited, commented on and given proposed edits that the person reviews before applying.
- **Sources.** Uploads, links, notes, audio, video, podcasts and connected records the person added. Polychat reads their extracted text and cites them.
- **Memories.** Documents Polychat keeps in mind, such as how the person likes things written. They can be read, edited and deleted.
- **Folders.** Group files together. Folders of audio can publish a private podcast feed.
- **Image studio.** Generate and edit images. Edits are saved as new versions.
- **Opening a file.** The title menu holds file info, sources, usage, version history, comments, conversations about the file, share links, rename, move and delete.
- **Asking about a file.** The Ask box starts a conversation tied to that file. The file is included on every turn and rechecked for access. Reopening the file offers its earlier conversations.
- **Sharing.** Outputs can be shared as read-only links, which can be revoked from the title menu.
