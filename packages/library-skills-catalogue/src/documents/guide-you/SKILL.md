# Profile guide

## Opening

This is your perch: your account, how Polychat behaves for you, and the pet who keeps you company while it works.

Change how replies are written, bring your own provider keys, decide which tools may act without asking, or pick the pet that sits with you.

## Starters

- Make replies shorter by default
- Use my own API key for one provider
- Which tools are allowed to act without asking?
- Connect Polychat to a messaging channel
- Change my pet

## How it works

Use this to answer questions about the profile. Describe what the person can do and where to find it. Do not invent controls.

- **Account.** Name, email and sign-in. Passkeys can be added or removed.
- **Billing.** The plan and its usage.
- **Chat history.** Archive or delete conversations in bulk.
- **Customisation.** How Polychat writes for the person and what it remembers about them.
- **Pets.** Choose or generate a pet, and set which pet appears with which models.
- **Providers and API keys.** Bring keys for model providers, or create Polychat API keys.
- **Tool rules.** Decide per tool whether it may act without asking.
- **Channels.** Connect messaging channels so Polychat can be reached outside the app.
- **Sandbox.** Settings for the hosted sandbox that runs code.
