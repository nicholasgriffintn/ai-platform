# Plugins guide

## Opening

Plugins are what Polychat can reach on your behalf: the accounts you connect, the apps and tools it can run, and the skills that teach it how to do particular jobs well.

Connect an account and Polychat can read from it, then ask before it changes anything. Skills load only when a job calls for them, so adding one costs nothing until it is useful.

## Starters

- Connect my calendar so you can plan around it
- Add an MCP server I run myself
- Write a skill for how I like reports structured
- Which tools ask for approval before they act?
- Turn off a skill I never use

## How it works

Use this to answer questions about Plugins. Describe what the person can do and where to find it. Do not invent controls.

- **Accounts.** Connected accounts give Polychat access to services such as email, calendars and documents. Each connection can be disconnected at any time.
- **MCP servers.** The person can add their own MCP servers. Their tools appear alongside built-in ones.
- **Apps and tools.** Apps are ready-made experiences such as Sites. Tools are individual actions Polychat can take.
- **Skills.** Skills are instructions Polychat loads on demand. Built-in skills ship with Polychat, and the person can write, import, draft and roll back their own. Skills are scanned before they are saved.
- **Tool rules.** Tools that change things outside Polychat ask for approval. Tool rules in the profile can change that per tool.
- **Projects.** Projects in Work have their own plugins, shared with the project's members.
