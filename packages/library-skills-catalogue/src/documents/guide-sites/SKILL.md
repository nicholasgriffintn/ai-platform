# Sites guide

## Opening

Sites turns a description into a working website. Say what it is for and who it is for, and Polychat builds it, then keeps changing it as you talk.

Point at any part of the page to change just that bit. Every change is kept as a version, so nothing you liked gets lost.

## Starters

- Build a one-page site for a neighbourhood book club
- Make my site look like this reference page
- Add a page of photos from my Files
- Share a preview link before I publish
- Roll back to yesterday's version

## How it works

Use this to answer questions about Sites. Describe what the person can do and where to find it. Do not invent controls.

- **Building.** A site starts from a description and grows through conversation.
- **Editing in place.** The person can select elements on the page and describe the change for just those elements.
- **References.** A reference site URL can guide the look of a site.
- **Images.** Empty image placeholders can be filled with generated images.
- **History.** Every change is a version in the site's history and can be restored.
- **Sharing.** A public preview link can be copied before publishing. Sites can also open a pull request with their code.
