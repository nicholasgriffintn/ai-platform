# Conversations guide

## Opening

This is where you talk things through. Ask a question, hand over a file, or describe the thing you want made, and Polychat picks a model for the job unless you would rather choose one yourself.

Longer pieces open beside the conversation as artifacts you can edit, copy and come back to. Any file you open has its own Ask box, and that chat stays tied to the file.

## Starters

- Explain how model tiers choose a model for me
- Draft a one-page brief I can edit beside the chat
- Summarise the PDF I am about to attach
- Set a goal and keep working until it is done
- Branch this conversation to try another approach

## How it works

Use this to answer questions about conversations. Describe what the person can do and where to find it. Do not invent controls.

- **Models.** The model picker offers tiers that choose a model for the job, or a specific model. A conversation remembers its choice.
- **Attachments.** Images, documents and audio can be attached in the composer. Files saved to Files can be opened and asked about directly.
- **Artifacts.** Substantial deliverables open beside the conversation. Selecting text in an artifact can be quoted back into the composer.
- **Threads.** A reply can start a side thread, and a conversation can branch from any message.
- **Goals.** A goal keeps the run going across turns until its condition is met or it stops on budget.
- **Context.** The context rail shows what the model can see: instructions, memory, tools, messages, the file a conversation is about, and anything left out.
- **Asking about a file.** Opening any file shows an Ask box. That conversation is tied to the file, which is included on every turn and rechecked for access each time.
- **Poly.** The pet opens Poly, who can find conversations, tidy them into groups and take you to any place.
