# Scope repository knowledge before retrieval

Project conversation history is shared. Checking only the person making a search cannot protect a private document once its passage becomes a saved tool result visible to other members.

Keep private repository imports personal. Admit only public repositories to project knowledge, and recheck public visibility and current membership before returning their content. Require each personal import's own live GitHub connection; never substitute the collector's credentials for another reader.

Reuse sources, collections, the document search tool and the durable task scheduler. Preserve a Git commit snapshot and a bounded tree-walk checkpoint, update stable source IDs, and remove absent documents only after a complete scan. Fence writes with the connection revision, worker lease and current project management authority.

Match phrases for connected knowledge and preserve pinned citations. Keep the existing vector index for personal uploads. Add semantic repository indexing only when it can retain the same source authority before reranking or model input.

Support private project knowledge only after downstream conversation history and recipients can enforce its source permissions. Previously public or deliberately shared passages remain in history; revocation prevents new retrieval.
